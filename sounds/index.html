Sounds & Audio

Ever since I was a child, I loved sounds. Over the years, I've explored computers, drums, bass guitars, and modular / hardware synthesizers in order to chase soundscapes, drone metal, ambient textures, and experimental electronica. Self-taught, minimal, and unfiltered.

Modular Synthesizer

Modular software synthesizer featuring flexible CV and audio signal routing. Built for experimental sound design, generative patching, cross-modulation, and complex drone soundscapes.

ANALOG EMULATION TOOL 02

Korg MS-20 Mini Clone

Software clone and emulation of the iconic semi-modular synthesizer. Accurately recreates the aggressive, non-linear behavior of dual resonant filters (High-Pass & Low-Pass), external patch bay, and raw analog character.

Dual Resonant Filters GitHub →
LAB TEST BENCH TOOL 03

Test Equipment Workbench

Early electronic music virtual studio inspired by 1950s–1960s broadcast and tape labs (WDR Köln, BBC Radiophonic Workshop). Built around laboratory signal generators, passive filters, attenuators, and classic tone-shaping techniques.

Signal & Tone Studio GitHub →
GENERATIVE AMBIENT TOOL 04

Aetherium

Cross-platform generative ambient soundscape and receptive music therapy sanctuary (macOS, Windows, Linux, iOS, Android, and Web PWA). Synthesizes continuous, never-repeating music in real time using Keplerian orbital physics, harmonic modal quantization, ISO-principle vectoring, and zero external audio samples.
