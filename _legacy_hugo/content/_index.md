<section class="projects-section">
    <h2>Projects</h2>
    <p>A few things I am (or was) involved in:</p>
    <ul>
        <li><b><a href="https://github.com/diorgulescu/DAMF">DAMF</a> (Device Automation & Management Framework)</b><br/>
        The goal here is to provide software test engineers and test lab managers/maintainers with a free & open system that makes it easy to manage embedded devices (boards, prototypes & other devices from the embedded universe) while also running automated test suites and generating test reports. This was initially inspired by an older version of Linaro's LAVA system.</li>
        <li><b><a href="https://github.com/diorgulescu/suckless-ubuntu">Suckless Ubuntu</a></b><br/>
        A small project that started out as a set of scripts I used for setting up a working Ubuntu-based Linux system tailored to my way of working. It relies on tools developed by suckless.org (dwm, dmenu, slstatus, surf, etc.). It's based on a minimal Ubuntu 18.04 installation.</li>
    </ul>
</section>
